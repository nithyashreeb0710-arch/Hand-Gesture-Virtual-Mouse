# Hand Gesture Recognition and Virtual Mouse Control

## About the Project
A real-time hand gesture recognition and virtual mouse control system developed using Python, OpenCV and MediaPipe.

This project allows users to control their computer mouse using hand movements detected through a webcam.

## Features
- Real-time detection of up to two hands
- Finger counting from 0 to 5
- Hand gesture recognition
- Virtual mouse cursor movement
- Mouse clicking using thumb and index finger pinch gesture
- Live camera display

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python HandGestureControl.py
```

## Controls

- M: Enable or disable virtual mouse
- Q: Exit the application
